# 放送事業の「Xデー」分析 (Japan Broadcasters X-Day Analysis)

## Overview
日本の在京キー局（民放5局）の放送事業単体が、いつ「赤字化（営業利益ゼロ）」の臨界点（Xデー）を迎えるのかをシミュレーションするインタラクティブな財務予測モデル・ダッシュボードです。

「広告売上の減少」と「放送インフラ・制作費の重い固定費構造」という構造的課題に対し、過去10年分の有価証券報告書および決算説明資料から抽出・分解した財務データをエビデンスとしています。

### Live Dashboard
👉 [Live Demo (GitHub Pages)](https://naohisastry.github.io/japan-broadcasters-xday-analysis/)

## Features
* **Scenario Analysis**: 「漸進的下落」「再編加速」「急速衰退」の3シナリオを切り替え可能。
* **Digital Shift Buffer**: 配信事業を含めた統合セグメントによる「延命効果」の可視化。
* **Interactive UI**: 各局のXデー予測年と、営業利益の将来推移をリアルタイムにチャート描画。
